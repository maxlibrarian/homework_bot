Telegram-бот для отслеживания проверки домашних работ в Яндекс Практикуме
Бот автоматически опрашивает API Яндекс Практикума и присылает уведомления в Telegram,
как только статус вашей домашней работы изменится:
«Принято», «Требует доработки», «На проверке» — вы узнаете об этом мгновенно!

# Возможности:

Регулярный опрос API Яндекс Практикума
Мгновенные уведомления при изменении статуса проверки
Безопасное хранение токенов через переменные окружения
Надёжная обработка ошибок и сетевых сбоев

# Технологии:

Python 3.9+
pyTelegramBotAPI — взаимодействие с Telegram
requests — HTTP-запросы к API Яндекс Практикума
logging — логирование
pytest — автоматизированное тестирование
.env — управление конфигурацией

# Установка и запуск:

git clone https://github.com/maxlibrarian/homework_bot.git
cd homework_bot

# Создайте виртуальное окружение и установите зависимости:

python -m venv venv
source venv/bin/activate          # Linux/macOS
# или
venv\Scripts\activate             # Windows
pip install -r requirements.txt

# Настройте переменные окружения

Создайте файл .env в корне проекта:
PRACTICUM_TOKEN=ваш_токен_от_Яндекс_Практикума
TELEGRAM_TOKEN=ваш_токен_бота_от_BotFather
TELEGRAM_CHAT_ID=ваш_ID_в_Telegram

# Как получить токены:

PRACTICUM_TOKEN — в личном кабинете Яндекс Практикума (раздел API)
TELEGRAM_TOKEN — у @BotFather
TELEGRAM_CHAT_ID — можно узнать у @userinfobot

# Запустите бота

python homework.py

Бот начнёт опрашивать API каждые 5–10 минут (настраивается) и присылать уведомления при изменениях.
